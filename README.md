# Symptoms & Systems: Revenue Rounds

A record-ready visual walkthrough series from GTM Diagnostics.

## Local development

```sh
npm install
npm run dev
```

The production build is generated with `npm run build` and deployed to GitHub Pages from the `main` branch.

## Content model

Public episode definitions live in `src/data/episodes.ts`. They contain only visible scene content and visual configuration. Private teleprompter scripts are deliberately maintained outside this repository.
